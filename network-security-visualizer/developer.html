Tentang pengembangan website

Network Security Visualizer dikembangkan sebagai media pembelajaran interaktif Informatika pada topik keamanan jaringan untuk peserta didik SMA. Media ini menampilkan jaringan komputer secara visual agar siswa dapat mengamati, menyelidiki, dan menalar sebelum menarik kesimpulan.

Tujuan pembuatan media

  • Membantu siswa mengamati perangkat dan koneksi jaringan kabel maupun nirkabel.
  • Melatih siswa membedakan fakta, dugaan, dan hal yang perlu dikonfirmasi.
  • Menghubungkan indikasi, ancaman, risiko, dan dampak secara bertahap.
  • Mengenalkan prinsip CIA dan upaya pengamanan beserta keterbatasannya.
